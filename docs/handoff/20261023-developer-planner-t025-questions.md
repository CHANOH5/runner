# T-025 앱 구현 중 기획 확인 4건

- From: developer
- To: planner
- 종류: 질문
- 관련 ID: S-003, S-010, S-061, S-031, F-002, F-004
- 상태: 답변됨

## 내용

모바일 앱 1차(T-025)를 PRD v1.10·와이어프레임대로 만들면서 아래는 임시로 정해 두었다. 맞는지, 바꿀지 알려 달라.

1. **S-003 "개인정보 처리방침 보기" 링크 대상** — 처리방침은 동의 대상이 아니라 게시 대상이라 약관 API(`GET /terms/current`)에 주소가 없다. 지금은 '개인정보 수집·이용 동의' 전문 주소를 연다. 처리방침 문서 주소는 어디서 받을지(원격 설정 / 고정 주소 [미정]) 정해 달라.
2. **S-010 추천 대회 제목** — PRD 6.7은 섹션 제목을 "{지역} 근처 대회"로 두지만, 내 지역 대회가 3개 미만이면 전국 대회로 채운다(`filledNationwide`). 실제 화면에서 "서울 근처 대회" 아래 부산 대회가 나와 어색하다. 전국으로 채웠을 때 제목(예: "추천 대회")이나 카드 표시를 바꿀지.
3. **S-061 관심 탭 "왼쪽 스와이프 → [해제]"** — 지금은 카드의 하트로 해제한다 (웹 확인에서 스와이프가 동작하지 않아서). 하트만으로 충분한지, 네이티브에서만 스와이프를 추가할지.
4. **S-031·S-005 날짜 입력** — PRD는 날짜 선택(달력, 미래 비활성)이다. 1차는 `YYYY-MM-DD` 입력 + [오늘]·[어제] 버튼이고 범위는 1990-01-01~오늘로 검사한다. 네이티브에서 달력 피커로 바꿀 예정인데, 웹 확인용으로 지금 방식을 유지해도 되는지.

## 기대하는 결과물 / 답변 형식
항목별로 "그대로" 또는 바꿀 내용. 필요하면 PRD에 반영.

## 답변 (받는 쪽이 작성)

(planner, 2026-10-27 — PRD v1.11 반영, 와이어프레임 S-003·S-005·S-010·S-031·S-061 수정)
1. **원격 설정으로 받는다.** `GET /app-config`에 `privacyPolicyUrl`(nullable)을 추가하고 `app_configs` 키(예: `privacy_policy_url`)로 owner가 관리자에서 바꾼다. 도메인(Q-12)이 없어도 임시 게시 주소를 넣을 수 있고, 개정 때 앱 배포가 필요 없다. S-003 링크와 S-065 "개인정보 처리방침" 행이 같은 값을 쓴다. 값이 null이면(개발 환경) 지금처럼 "개인정보 수집·이용 동의" 전문을 연다. 운영 출시 전 값 입력은 필수 (P-LEGAL 체크리스트에 추가). PRD 4.2. **API 변경 있음: `GET /app-config` 응답에 `privacyPolicyUrl: string(url) | null` 추가, `PUT /app-configs/{key}` 허용 키에 `privacy_policy_url` 추가.**
2. **바꾼다.** `filledNationwide = true`면 섹션 제목을 **"추천 대회"**로, 제목 아래 회색 한 줄 **"{지역} 대회가 적어 전국 대회도 함께 보여드려요"**. 내 지역 대회만이면 지금처럼 "{지역} 근처 대회". 카드에는 이미 지역이 보이므로 카드 표시는 그대로. 정렬은 내 지역 대회 먼저, 보충분 뒤 (현재 응답 순서가 이렇지 않으면 맞춰 달라). PRD 6.7. **API 변경 없음** (`filledNationwide`·`regionCode`로 충분).
3. **하트만으로 충분 — 스와이프는 넣지 않는다 (네이티브도).** 다른 목록과 같은 동작이라 배울 것이 적고 웹·네이티브가 같다. 관심 탭에서 하트를 끄면 카드가 빠지고 토스트 "관심 대회에서 뺐어요" + [되돌리기](5초, 누르면 다시 PUT). 참가 예정인 대회는 기존 확인 다이얼로그 먼저. PRD 6.19. **API 변경 없음.**
4. **웹 확인용은 지금 방식 유지 가능.** 제품 사양은 **달력 피커(미래 비활성) + 빠른 선택 칩 [오늘] [어제]** — 1차의 [오늘]·[어제]가 좋아서 네이티브에도 남기기로 했다. `YYYY-MM-DD` 직접 입력은 웹 미리보기 빌드에서만. 범위 검사(1990-01-01~오늘)는 그대로. PRD 4.4 (S-005·S-031 공통). **API 변경 없음.**
