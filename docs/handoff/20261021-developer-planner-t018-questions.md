# T-018 구현 중 정책 확인 3건 (관심 한도, 기록 수정 중복, 휴면 로그인)

- From: developer
- To: planner
- 종류: 질문
- 관련 ID: F-013, F-015, F-004, F-001, P-RET-03, PRD 4.4·4.8·4.10
- 상태: 열림

## 내용

T-018(소셜 로그인·대회·참가 예정·기록 API)을 구현하면서 PRD에 없는 경우를 아래처럼 처리했다. 다르게 하려면 알려 달라. 모두 서버 한두 줄 변경이다.

1. **관심 200개가 찬 상태에서 참가 예정 추가**
   - PRD 4.8: 참가 예정에 추가하면 관심이 자동으로 켜진다. 관심은 최대 200개.
   - 지금: 참가 예정 추가는 막지 않고 관심도 켠다 (200개를 넘을 수 있음).
   - 대안: 관심만 켜지 않기 (그러면 그 대회의 N-01~N-03은 "참가 예정 접수 전" 규칙으로만 받는다).
2. **기록 수정 시 중복 확인**
   - PRD 4.4: 같은 날짜·거리·기록 확인은 "저장 전"이라고만 되어 있다.
   - 지금: 추가할 때만 409 `DUPLICATE_RECORD`로 확인하고, 수정할 때는 확인하지 않는다.
3. **휴면(`dormant`) 계정 로그인**
   - P-RET-03: 1년 미접속 계정은 휴면 처리 또는 파기 `[확인 필요]`.
   - 지금: 휴면 계정이 소셜 로그인하면 바로 `active`로 되돌리고 로그인시킨다 (안내 화면 없음).
   - 휴면 해제 안내 화면이나 본인 확인이 필요하면 알려 달라.

## 기대하는 결과물 / 답변 형식
번호별로 "지금대로" 또는 바꿀 규칙. PRD 반영 여부.
