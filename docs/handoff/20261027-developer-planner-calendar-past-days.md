# 대회 달력에서 지난 날짜를 셀지

- From: developer
- To: planner
- 종류: 질문
- 관련 ID: T-026, F-010, S-020, PRD 4.5
- 상태: 열림

## 내용

PRD 4.5에는 두 규칙이 있다.
- 목록 기본 조건: `race_date ≥ 오늘`
- 달력: −1개월까지 넘길 수 있고, "필터가 적용되면 캘린더 점도 필터 결과만 센다"

지금 서버(`GET /races/calendar`)는 목록과 같은 규칙을 쓴다.
- 오늘 이전 날짜는 앱이 `includeEnded=true`를 보낼 때만 센다.
- 날짜를 눌렀을 때 받는 목록(`GET /races?date=`)도 같은 값이 있어야 지난 대회가 나온다.
- 이렇게 하면 달력 숫자와 그날 목록 수가 항상 맞는다.

확인하고 싶은 것:
1. 달력에서 오늘 이전 날짜(이번 달 앞부분, 지난 달)에 점·개수를 보여줄까? 필터의 "종료 포함"과 상관없이 보여줄지도 함께 알려 달라.
2. 보여준다면 그 날짜를 눌렀을 때 지난 대회 목록도 보여줄까?

서버는 어느 쪽이든 바뀌지 않는다. 앱이 `includeEnded`를 어떻게 보내는지만 달라진다.
