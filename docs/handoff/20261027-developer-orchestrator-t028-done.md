## 내용

브랜치 `claude/app-t028`(main `cae6ce5` 기준). push·병합하지 않았다. `packages/shared`·`server/` 변경 없음, 서버 변경 요청도 없음.

1. **S-020 캘린더 지난 날짜 (PRD v1.12 4.5)**: 이번 달 앞부분·지난달 날짜에도 점·개수(회색으로 흐리게)를 표시하고, 누르면 그날 지난 대회(`종료` 배지)를 보여준다. 캘린더 보기에서는 "종료 포함"과 상관없이 `GET /races/calendar`와 `GET /races?date=` 둘 다 `includeEnded=true`. 다른 필터는 두 요청에 똑같이 적용하고, 기간 필터(이번 달 등)는 달이 기간이라 캘린더에 보내지 않는다. 리스트·검색은 계속 "종료 포함"을 따른다.
2. **임시 처리 교체**: S-021 결과 수 → `GET /races/count`("128개 대회 보기", 0개면 비활성), 캘린더 → `GET /races/calendar`(그날 목록은 20개씩 이어 받기), 공지 → `GET /notices/{id}`(줄바꿈 유지, 본문 URL 링크 → 인앱 브라우저, 하단 [대회 보기]/[대회 찾아보기], 410 "내려간 공지예요"). 필터 시트 "종료 포함" 아래 "캘린더는 지난 날짜도 함께 보여요".
3. **공유 타입 정리**: 앱 전용 `AppConfigRes`를 지우고 공유 `AppConfig`를 그대로 쓴다. 형식이 틀린 `privacyPolicyUrl`을 null로 너그럽게 받던 처리는 없앴다 (공유 스키마·서버가 http(s) 주소 또는 null만 내보냄). 테스트도 공유 스키마로 바꿨다.

**확인**: 웹(서버 :3001, 앱 :8081)에서 10월 달력의 10/4(지난 대회 1개)가 회색 `●1`로 보이고, 누르면 "[개발] 대구 가을 마라톤 · 종료"가 나온다. 요청: `calendar?month=2026-10&includeEnded=true`, `races?includeEnded=true&date=2026-10-04`. 필터 시트 "5개 대회 보기"(count API). 공지는 시드 데이터가 없어 렌더 테스트로 확인.
**테스트**: 앱 96 통과(기존 85 + 11). lint·typecheck 통과.

**보드 갱신 요청**: T-028 → `검토`.
