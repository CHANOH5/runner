# 알림 워커 구현 중 문구·경계 규칙 확인 4건

- From: developer
- To: planner
- 종류: 질문
- 관련 ID: F-014, N-01~N-06, PRD 7.1·7.2, P-NOTI-05, P-RET-03
- 상태: 열림

## 내용

T-019(알림 발송 워커)를 PRD 7장대로 구현했다. 아래 4건은 PRD에 없거나 규칙끼리 맞지 않아 이렇게 처리했다. 바꿀 것이 있으면 알려 달라. 모두 서버 문구·조건 수정만 하면 된다.

1. **묶음 푸시 문구 (PRD 7.1에는 N-01 예시 하나만 있음)**
   - 같은 사용자·종류·예약 시각 2건 이상이면 푸시 1건. 본문은 대회명을 쉼표로 잇고 60자를 넘으면 "외 n개"로 줄인다. 탭하면 S-011.

   | kind | 묶음 제목 (초안) |
   |---|---|
   | N-01 | 내일 접수가 시작되는 관심 대회 {n}개 (PRD 예시) |
   | N-02 | 곧 접수가 열리는 대회 {n}개 |
   | N-03 | 내일 접수가 마감되는 대회 {n}개 |
   | N-04 | 일주일 남은 대회 {n}개 |
   | N-05 | 내일 열리는 대회 {n}개 |
   | N-06 | 취소된 대회 {n}개 / 연기된 대회 {n}개 / 일정이 바뀐 대회 {n}개 |

2. **긴 대회명 줄이기**
   - PRD 7.2: 넘치면 대회명을 20자로 줄이고 "…".
   - 그런데 N-01 제목 "내일 {대회명} 접수가 시작돼요"는 고정 문구만 12자다. 20자 + "…"로 줄여도 33자라 30자 제한을 넘는다. N-03 제목도 34자가 된다.
   - 구현: 20자로 줄여도 넘치면 들어갈 때까지 더 줄인다 (최소 8자).
   - 대안: 제목 상한을 늘리거나, 해당 문구를 짧게 바꾸기.
3. **워커가 늦게 돌았을 때 (장애·재시작)**
   - 문구가 사실과 달라지면 보내지 않게 했다.
     - N-01 "내일 접수가 시작돼요": 오픈 전날까지만 보낸다. 오픈 당일이 되면 취소.
     - N-03 "내일 마감돼요": 마감 전날까지만.
     - N-02: 오픈 시각 전까지만 (시각 미정이면 오픈일까지).
     - N-04 "일주일 남았어요": 예약 시각부터 24시간 안에만.
     - N-05: 대회 전날까지만.
   - 정상일 때는 영향이 없다. 장애 복구 직후에만 해당한다.
4. **휴면 계정과 N-06 (대회 취소·연기·일정 변경)**
   - P-RET-03: 휴면 중에는 서비스·마케팅 푸시를 보내지 않는다 (법정 고지는 예외).
   - 지금은 N-06도 휴면 계정에 보내지 않는다 (앱 내 알림 행도 만들지 않음).
   - 대회 취소는 환불과 관련될 수 있어, 법정 고지처럼 휴면 계정에도 보낼지 정해 달라.

## 기대하는 결과물 / 답변 형식
번호별로 "지금대로" 또는 바꿀 문구·규칙. PRD 7장 반영 여부.
