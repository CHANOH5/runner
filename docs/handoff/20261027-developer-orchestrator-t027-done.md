1. **S-010 추천 대회**: `filledNationwide`면 제목 "추천 대회" + 회색 안내 "{지역} 대회가 적어 전국 대회도 함께 보여드려요", 아니면 "{지역} 근처 대회". 내 지역 대회 먼저 — 서버(`home/service.ts`)가 이미 내 지역 → 보충 순서로 주므로 순서가 바뀌는 일은 없고, 앱은 안전하게 한 번 더 안정 정렬만 한다. 프로필 지역이 없으면 제목만 "추천 대회".
2. **S-061 관심 해제**: 스와이프 없음. 관심 탭에서 하트를 끄면 카드가 바로 빠지고 토스트 "관심 대회에서 뺐어요" + [되돌리기](5초, 누르면 PUT 후 다시 표시). 참가 예정 대회는 기존 확인 다이얼로그가 먼저.
3. **처리방침 링크 (S-003, S-065)**: `GET /app-config`의 `privacyPolicyUrl`을 앱 쪽 스키마 `AppConfigRes`(공유 `AppConfig.extend`)로 선택적으로 읽는다. 없음·null·형식 오류는 null → '개인정보 수집·이용 동의' 전문.
4. **S-005·S-031 날짜**: 네이티브는 달력 피커(`@react-native-community/datetimepicker` 9.2.1, Expo 호환 버전, config plugin 추가 — 미래·1990년 이전 비활성) + [오늘]·[어제]. 웹 미리보기는 기존 직접 입력. 네이티브 동작은 렌더 테스트로 확인(웹에서 볼 수 없음).
