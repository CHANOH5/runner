## 내용

브랜치 `claude/app-phase1-17f930`에 T-025를 끝냈다. push·main 병합은 하지 않았다. 사용자 승인 후 병합해 달라.

**구현한 것**
1. 새 워크스페이스 `app/` — Expo SDK 58 (RN 0.88, React 19.3), TypeScript strict, Expo Router, TanStack Query + Zustand. 루트 `pnpm lint`·`typecheck`·`test`와 CI(기존 단계)에 포함된다.
2. API 클라이언트: 공유 Zod 스키마로 응답 검증, 토큰 저장(SecureStore)·자동 갱신(동시 요청도 갱신 1번), 에러 코드 → 한국어 문구, 최소 앱 버전(426)·약관 재동의(403)·점검(503) 게이트.
3. 화면: S-001~S-006(가입·약관·프로필·만 14세 판정·기록·알림 권한, 재동의·휴면 해제·강제 업데이트·점검), S-010·S-011, S-020~S-024(리스트·캘린더·검색·필터·상세·참가 예정·제보), S-030~S-033(기록·예측·페이스 전략, 면책 문구·신뢰도·'기록이 바뀌었어요 · 다시 예측'), S-060~S-066(탈퇴 포함). 하단 탭 4개, 라이트·다크.
4. 참가 예정·접수 상태: 공식 링크에서 돌아왔을 때 묻기(10초·24시간·3회 규칙, 기기 저장), 상태 선택 시트, '접수 못 함' → 해제 질문, 공식 접수 안내 시트(P-RACE-01). 용어는 '참가 예정'.
5. 지도: `MapView` 래퍼만 두고 자리 표시 + [길찾기]·[지도 앱에서 검색] (D-008 확정 전, 네이버 SDK 미연동).
6. 로컬 확인: Expo 웹. `pnpm dev:app` → API :3000 + 앱 http://localhost:8081. 웹은 Metro가 `/v1`을 API로 프록시(서버 CORS 변경 없음).
7. 서버 변경 (최소): **개발 전용 로그인** — `DEV_LOGIN=true`이면 소셜 토큰 자리에 `dev:{이름}`을 받는다. `NODE_ENV=production`이면 설정 단계에서 거부(서버가 시작하지 않음). 테스트 7개 추가, tech/03 8장·tech/06에 기록.
8. Development Build 설정(`app.json`, `eas.json`)만 만들었고 빌드는 하지 않았다.

- 테스트: 서버 236 (기존 229 + 개발 로그인 7), 관리자 9, 앱 74 (단위 61 + 화면 렌더 13). lint·typecheck 통과.

**결정 요청**
1. 서버 미구현 API 3개를 다음 서버 작업으로 배정할지: `GET /races/count`(필터 결과 수), `GET /races/calendar`(달력 날짜별 수), `GET /notices/{id}`(공지 상세). 지금 앱은 목록 첫 50개로 세거나("50개 이상"), 그 달 목록을 모아 세거나, 알림 본문을 보여주는 것으로 대신한다 (tech/03 9-0-2).
2. 앱 식별자: bundle id·Android package를 임시로 `app.berun.dev`, 스킴 `berun`으로 두었다. 서비스명(D-009)과 함께 확정이 필요하다 (스토어 등록·푸시·지도 앱 `appname`에 쓰임).
3. EAS 프로젝트 생성(사용자 Expo 계정)과 Development Build 첫 빌드 시점. 푸시 토큰(EAS projectId 필요)과 실기기 확인이 여기에 걸려 있다. 이 Mac에 Xcode가 없으면 EAS 클라우드 빌드로 한다.

**웹에서 안 되는 것** (README "모바일 앱"): SecureStore → localStorage 대체, 푸시 권한·토큰 등록 없음, 지도는 자리 표시, 지도 앱 → 웹 지도, 인앱 브라우저 → 새 탭. 실제 소셜 로그인 SDK는 키 발급 후.
