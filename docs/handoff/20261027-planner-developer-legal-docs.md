## 내용

`docs/planning/legal/`에 약관·방침 초안을 만들었다 (법률 검토 전, 게시 금지). 문서 목록·버전 규칙·검토 체크리스트는 `legal/README.md`.

### 1. 게시용 페이지 호스팅 (요청)
- `terms_versions.content_url`(service·privacy·marketing)과 원격 설정 `privacyPolicyUrl`은 웹 주소가 필요하다. 도메인(Q-12)이 정해지기 전에도 쓸 수 있게 **정적 페이지 호스팅 방법**을 정해 달라 (예: S3 + CloudFront 임시 주소, 마크다운 → HTML 변환).
- 요구: 모바일 웹뷰에서 읽기 좋은 단순 페이지, `noindex` 필요 없음(공개 문서), 버전별 주소 고정(예: `/terms/service/v1.0`) — 개정 후에도 이전 버전을 볼 수 있어야 동의 이력과 맞는다.
- 법률 검토 전 초안을 운영 환경에 올리지 않는다. 개발·스테이징에는 초안을 올려도 된다 (화면에 "초안" 표시 유지).

### 2. `terms_versions` 데이터 (요청)
- 게시본 v1.0이 확정되면 `service`(필수), `privacy`(필수), `marketing`(선택) 각 1행을 시드/관리 방식으로 넣는다. `location`·`night_push`는 Phase 1에 넣지 않는다.
- **"개인정보 수집·이용 동의"(`kind = privacy`, 필수 동의)와 "개인정보 처리방침"(`privacyPolicyUrl`, 게시)은 다른 문서**다. `privacy` 행의 `content_url`에 처리방침 주소를 넣지 않게 주의 (지금 S-003 대체 동작은 PRD 4.2대로 유지).
- 법률 검토 결과 필수 `privacy` 동의를 없애게 될 수 있다 (`legal/README.md` 1장 `[확인 필요]`). 그 경우 가입 API의 "필수 2개" 검증을 "service 1개"로 바꿔야 하니 미리 알고 있어 달라 (지금은 변경 요청 아님).
