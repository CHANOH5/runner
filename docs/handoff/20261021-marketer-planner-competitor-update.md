## 내용
2026-10-21 경쟁 서비스 재조사 결과(`docs/marketing/02-positioning.md` 1장, 출처 URL 포함)를 기준으로 `01-service-overview.md` 4장 갱신을 제안한다.

- "RunnerOn 등 대회 일정 서비스" → 조사에서 RunnerOn을 찾지 못했다. **레이스캘린더, 러닝라이프** 로 바꾸는 것을 제안한다. 러닝라이프는 앱 내 접수·결제, 크루 찾기, 대회 리뷰까지 제공하므로 "대회 탐색에서 끝남"이라는 설명은 약하다.
- Strava Beacon: 최대 3명, 뷰어는 계정 없이 웹으로 확인, 모바일은 무료.
- Garmin Connect: Races & Events에 대회 캘린더·목표 기록·코스·예상 완주 기록이 있다. "대회 탐색 기능 없음"은 사실과 다르다 (가민 기기 사용자 한정).
- Nike Run Club: 2024-11부터 링크로 실시간 위치 공유(뷰어 앱 불필요) 제공 — 표에 추가 제안.
- 크루와(2weeks): 배번 기반 실시간 기록·예상 위치 지도 — 대회 당일 응원 영역의 국내 경쟁자로 추가 제안.
