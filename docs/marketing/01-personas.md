# 01. 페르소나

- 담당: 마케터
- 상태: v1 가설 — **러너 인터뷰(T-014)로 검증 전**
- 관련: `../planning/01-service-overview.md`, `../planning/02-features.md`

> 아래 페르소나는 가설이다. 인터뷰 10명을 마친 뒤 실제 발언을 근거로 수정하고, 바뀐 내용은 기획자에게 handoff로 알린다.

---

## 페르소나 요약

| 구분 | 페르소나 | 핵심 니즈 | 주 사용 단계 | 유료 가능성 |
|---|---|---|---|---|
| 핵심 1 | 첫 하프 도전 직장인 **"지원"** | 내 수준에 맞는 대회, 현실적인 목표, 혼자가 아닌 느낌 | Discover → Predict → Live | 중 |
| 핵심 2 | 러닝 크루 리더 **"태호"** | 크루원 대회 일정·목표 한눈에, 당일 위치 확인 | 전체, 특히 Crew | **높음** |
| 핵심 3 | 기록 갱신형 마스터즈 **"경민"** | 정밀한 예측과 페이스 전략, 같은 목표의 페이스 메이트 | Predict → Live → Result | 높음 |
| 보조 | 응원하는 가족 **"미경"** | 러너가 지금 어디쯤인지, 언제 도착하는지 | Live (응원 웹) | 없음 (확산 채널) |

## 핵심 1 — 지원 (첫 하프 도전 직장인)

| 항목 | 내용 |
|---|---|
| 기본 정보 | 31세, 서울 마포구, IT 회사 마케터 |
| 러닝 경력 | 1년 3개월. 10K 대회 3회 완주 (최고 기록 55분) |
| 사용하는 도구 | 애플워치 + Nike Run Club, 인스타그램 러닝 계정 팔로우 |
| 소속 | 크루 없음. 가끔 회사 동료 1명과 뜀 |
| 목표 | 내년 봄 첫 하프 완주, 2시간 안에 |
| 대회 정보를 얻는 곳 | 인스타그램, 지인 추천, 대회 일정 사이트 |

**불편함**
- 인기 대회는 접수 오픈 몇 시간 만에 마감되는데, 오픈일을 자주 놓친다.
- 하프를 몇 분에 뛸 수 있을지 모르겠다. 처음에 너무 빨리 달려서 후반에 무너질까 걱정된다.
- 대회에 혼자 나가면 출발선에서 어색하고, 비슷한 속도로 같이 뛸 사람이 있으면 좋겠다.

**BeRun이 주는 가치**
- 관심 대회 접수 오픈 알림 (F-014)
- 10K 기록으로 하프 예상 기록 범위와 구간 페이스 전략 (F-020, F-021)
- 같은 대회 2시간 목표 페이스 그룹 (F-032)

**인용 (가설)**
> "같이 뛸 사람이 있으면 대회에 더 자주 나갈 것 같아요."

**마케팅 메시지 방향**: "첫 하프, 혼자 뛰지 마세요."

---

## 핵심 2 — 태호 (러닝 크루 리더)

| 항목 | 내용 |
|---|---|
| 기본 정보 | 38세, 경기 성남시, 회사원 |
| 러닝 경력 | 7년. 풀코스 9회, 최고 기록 3시간 28분 |
| 사용하는 도구 | 가민 포러너, Strava, 카카오톡 오픈채팅(크루 공지) |
| 소속 | 동네 러닝 크루 리더 (멤버 40명, 정기 활동 15명) |
| 목표 | 크루원들이 다치지 않고 목표를 이루는 것 |

**불편함**
- 크루원 누가 어느 대회에 나가는지 오픈채팅과 구글 시트로 관리한다. 자꾸 누락된다.
- 대회 당일 크루원들이 지금 어디쯤인지 몰라서 응원 포인트를 잡기 어렵다.
- 가민 LiveTrack은 가민 사용자만 쓸 수 있어서 크루 전체에 적용할 수 없다.

**BeRun이 주는 가치**
- 크루원 참가 대회·목표 일괄 확인 (F-061)
- 대회 당일 크루원 위치를 지도에서 확인 (F-042, 친구 공개 범위)
- 크루 페이스 그룹으로 함께 출발 (F-032, F-035)

**인용 (가설)**
> "단체 접수 엑셀 정리하는 데만 매번 몇 시간씩 걸려요."

**마케팅 의미**: **초기 확산의 핵심 채널.** 크루 리더 한 명을 확보하면 크루원 10~40명이 따라온다. 초기 마케팅은 크루 리더 섭외에 집중한다.

**마케팅 메시지 방향**: "크루의 대회 일정, 이제 오픈채팅 말고 한곳에서."

## 핵심 3 — 경민 (기록 갱신형 마스터즈 러너)

| 항목 | 내용 |
|---|---|
| 기본 정보 | 45세, 부산, 자영업 |
| 러닝 경력 | 12년. 풀코스 20회 이상, 최고 기록 3시간 05분 |
| 사용하는 도구 | 가민 상위 모델, Strava 유료, 훈련 계획 앱 |
| 목표 | 서브3 (3시간 이내 완주) |

**불편함**
- 기존 예측은 코스 특성(고도, 바람)과 기온을 반영하지 않는다.
- 서브3를 노리는 같은 대회 참가자와 미리 연결되고 싶다.
- 대회가 끝나면 예측과 실제를 비교한 구간별 분석이 부족하다.

**BeRun이 주는 가치**
- 코스·기온 보정 예측 (F-022), 개인화 예측 (F-023)
- 서브3 페이스 그룹 매칭 (F-032)
- 예측 vs 실제 리포트 (F-051)

**인용 (가설)**
> "예측이 정확하다면 한 달에 몇천 원은 기꺼이 낼 수 있어요."

**마케팅 메시지 방향**: "이 코스, 이 날씨에서 당신의 기록."

## 보조 — 미경 (응원하는 가족)

| 항목 | 내용 |
|---|---|
| 기본 정보 | 58세, 지원의 어머니 또는 태호의 배우자 |
| 디지털 친숙도 | 카카오톡, 유튜브 사용. 새 앱 설치는 꺼림 |
| 상황 | 대회장에 응원하러 오거나 집에서 결과를 기다림 |

**불편함**
- 응원하러 가도 러너가 언제 지나가는지 몰라 오래 기다린다.
- 무사히 뛰고 있는지 걱정된다.

**BeRun이 주는 가치**
- **앱 설치 없이** 카카오톡으로 받은 링크 하나로 위치와 예상 도착 시간 확인 (F-043, W-001)
- 이모지 응원 보내기 (F-046)

**마케팅 의미**: 응원 웹 페이지 하단에 "나도 대회 찾아보기" 링크를 둔다. 응원자가 러너로 전환될 수 있는 **바이럴 접점**이다.

> 주의: 위치 공유를 "안전 보장"으로 표현하지 않는다 (P-COM-07). "응원", "함께"의 프레임을 쓴다.

## 안티 페르소나 (타깃이 아님)

| 대상 | 이유 |
|---|---|
| 대회에 나가지 않는 가벼운 조깅족 | 대회 중심 서비스와 맞지 않음. Nike Run Club 같은 앱이 더 적합 |
| 엘리트 선수 | 전문 코칭과 장비 연동 수준의 요구 |
| 만 14세 미만 | 가입 불가 (P-ACC-01) |
| 타인의 위치를 보려는 목적의 사용자 | 정책상 차단 대상 (P-COM-04) |

## 검증할 가설 (T-014 인터뷰)

| 가설 | 검증 질문 |
|---|---|
| H1. 러너는 대회 접수를 놓친 경험이 있다 | "최근 1년간 원하던 대회 접수를 놓친 적이 있나요?" |
| H2. 혼자 대회에 나가는 러너는 같은 페이스의 동행을 원한다 | "모르는 사람과 페이스 그룹으로 함께 뛸 의향이 있나요? 걱정되는 점은?" |
| H3. 위치 공유에 대한 거부감은 공개 범위를 조절할 수 있으면 줄어든다 | "가족에게만 / 같은 대회 참가자에게 대략적인 구간만 공개한다면?" |
| H4. 크루 리더는 크루 관리 기능에 돈을 낸다 | "지금 크루 관리에 쓰는 시간은? 월 2만 원이면?" |
| H5. 기록 갱신형 러너는 정밀 예측에 돈을 낸다 | "지금 쓰는 유료 러닝 서비스는? 무엇에 돈을 내나요?" |
