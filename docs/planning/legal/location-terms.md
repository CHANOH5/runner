## 서비스 요약 (약관에 반영할 사실)
- 위치 공유는 **기본 OFF**, 대회별로 회원이 직접 켜고, 대회 당일 운영 시간에 **시작 버튼을 직접 눌렀을 때만** 수집한다 (P-LOC-01~03).
- 정확한 위치는 회원이 고른 친구와 응원 링크를 가진 사람에게만, 같은 대회 참가자에게는 1km 단위 구간만 보여준다 (P-LOC-10~14).
- 대회 코스 반경 밖 위치는 다른 사람에게 보여주지 않는다 (P-LOC-04).
- 중지는 한 번 탭, 5초 안에 시청자 화면에서 사라짐. 결승 후·제한 시간 후·코스 이탈 시 자동 종료 (P-LOC-30~32).
- 위치 원본은 세션 종료 후 7일 뒤 자동 파기 (P-RET).
- 응급 구조 서비스가 아니다 (P-COM-07). 위치 공유는 무료 (P-PAY-03).
