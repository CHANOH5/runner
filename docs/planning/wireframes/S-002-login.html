PRD 참조 · 메모

  • 동의는 S-003에서 따로 받으므로 하단 "로그인하면 동의" 문구 없음. [둘러보기] 없음 (PRD 6.2, 9장)
  • iOS에서 Apple 버튼은 다른 소셜 버튼과 같은 크기 (4.1 수용 기준)
  • 휴면(dormant) 계정: 소셜 로그인 = 본인 확인, 추가 확인 없이 해제 + 안내 화면 1회 (PRD 4.1 휴면 해제, P-RET-03). 닫기·뒤로 = [시작하기]
