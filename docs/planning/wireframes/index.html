보는 법

  • 화면마다 상태(기본 · 로딩 · 빈 · 에러 등)를 나란히 그렸다. PRD에 정의된 상태만 그렸다.
  • 프레임 안의 버튼·카드는 해당 화면으로 가는 링크다. 하단 탭은 홈/대회/기록/마이 4개 (D-012).
  • 회색 점선 박스 = 이미지·지도 등 자리. 진한 버튼 = 주 동작, 점선 버튼 = 비활성.
  • 문구는 PRD 문구를 그대로 썼다. {}는 변수, [미정]은 PRD 11장 미정 항목.
  • 하위 화면(전체 화면 지도, 공지 상세, 재동의, 가입 중단 등)은 부모 화면 페이지 안의 상태로 그렸다. 화면 수 24개에 포함하지 않는다.
