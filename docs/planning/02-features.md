## 모듈별 상세

### 계정 (F-001 ~ F-004)
- **F-001 소셜 로그인**: 카카오, Apple, Google. iOS에서 다른 소셜 로그인을 제공하면 Apple 로그인도 제공해야 한다. Android의 Apple 로그인은 Phase 1에서 제외한다 (D-016). 이메일·비밀번호 가입은 MVP에서 제외한다.
- **F-002 동의**: 필수(이용약관, 개인정보 수집·이용)와 선택(마케팅 수신, 위치기반서비스 이용약관)을 **분리**한다. 위치기반서비스 약관은 Phase 3 진입 시 별도로 받는다.
- **F-003 프로필**: 실명은 받지 않는다. 생년은 연도만 받는다 (만 14세 확인용). 성별은 선택 항목이다.
- **F-004 최근 기록**: 거리(5K/10K/Half/Full/기타), 기록, 날짜, 대회명(선택). 예측의 입력값이 된다.
- 수용 기준
  - 로그인부터 프로필 입력 완료까지 1분 이내에 끝난다.
  - 만 14세 미만이면 가입이 중단되고 안내 문구가 나온다.

### Discover (F-010 ~ F-016)
- **F-010 목록·캘린더**: 월간 캘린더 보기와 리스트 보기를 전환한다. 기본 정렬은 대회일 가까운 순이다.
- **F-011 필터**: 지역(시·도), 기간, 종목 거리, 접수 상태(접수 예정/접수 중/마감/종료), 참가비 범위.
- **F-012 대회 상세**: 대회명, 일시, 장소, 종목별 정보(거리, 참가비, 제한 시간, 출발 시각), 접수 기간, 공식 홈페이지·접수 링크, **대회장 위치 지도**(네이버 지도, D-008 — 좌표가 없으면 안내 박스와 지도 앱 검색), 공식 코스 안내 링크(있으면, 코스 경로 지도는 Phase 2 이후), 정보 출처와 최종 확인일.
- **F-014 알림**: 관심 대회의 접수 오픈 D-1·오픈 10분 전, 마감 D-1, 대회 D-7·D-1, 대회 취소·연기·일정 변경. 발송 시각·문구는 `05-prd-phase1.md` 7장.
- **F-015 참가 등록**: "이 대회에 나간다" 표시. 종목과 목표 기록을 입력한다. 실제 접수는 외부 링크로 안내하며 앱은 접수를 대행하지 않는다.
- 수용 기준
  - 대회 상세에 정보 출처와 최종 확인일이 항상 표시된다.
  - 관심 등록한 대회의 접수 오픈 알림이 오픈 시각 기준 ±10분 안에 발송된다. (구체화: 오픈 10분 전 알림을 `오픈 −10분 ~ 오픈 시각` 사이에 발송, 05 문서 4.9)

### Predict (F-020 ~ F-023)
- **F-020 기록 예측**: 기본 식은 Riegel 공식 `T2 = T1 × (D2 / D1)^1.06`.
  - 입력 기록이 여러 개면 최근 기록과 목표 거리에 가까운 기록에 가중치를 준다.
  - 5K → Full처럼 거리 차이가 크면 신뢰도를 "낮음"으로 표시하고 범위(예: 4:05~4:25)로 보여준다.
  - 가중치·신뢰도·범위 수치는 `05-prd-phase1.md` 5장에서 확정 (`riegel-1.06-v1`).
- **F-021 페이스 전략** (Phase 1 P0, D-011 — 국내 대회 앱 대비 Phase 1의 핵심 차별점): 평균 목표 페이스, 구간별 스플릿(15km 미만 1km, 이상 5km), 이븐 페이스와 네거티브 스플릿 두 가지 안. 계산 규칙은 `05-prd-phase1.md` 5.6.
- **F-022 코스 보정**: 누적 상승 고도, 예상 기온으로 보정 (Phase 2).
- **F-023 개인화 예측**: 최근 훈련량, 장거리 주행 빈도를 반영한다. AI는 "왜 이 예측인지" 설명을 생성하는 데 사용한다 (Phase 4).
- 수용 기준
  - 예측 결과에 **면책 문구와 신뢰도**가 항상 표시된다 (P-PRED).

### Social (F-030 ~ F-036) — Phase 2
- **F-030 참가 인증**: 단계별 인증 수준 (P-VER). 미인증 사용자는 페이스 그룹 참여만 가능하고 라이브 지도에는 나타나지 않는다.
- **F-032 페이스 그룹**: 같은 종목에서 목표 페이스를 15초/km 단위로 묶는다 (예: 5'30"~5'44"). 그룹 정원은 [미정].
- **F-034 친구**: 상호 승인으로만 맺어진다. 친구만 정확 위치를 볼 수 있다.
- **F-036 차단·신고**: 차단하면 상대에게 내 프로필, 페이스 그룹 내 존재, 라이브 위치가 모두 숨겨진다.

### Live (F-040 ~ F-047) — Phase 3
- **F-040 위치 공유 설정**: 대회별로 켠다. 공개 범위를 고른다.
  - `비공개` — 기록만 남기고 아무에게도 공유하지 않는다
  - `친구만` — 승인한 친구·응원 링크 소지자에게 정확 위치를 공유한다
  - `친구 + 참가자` — 친구에게 정확 위치, 같은 대회 인증 참가자에게 대략 구간(예: "7~8km 구간")
- **F-041 라이브 세션**: 시작은 반드시 사용자가 직접 누른다. 자동 시작은 없다.
- **F-043 응원 링크**: 추측할 수 없는 토큰 URL. 유효 시간은 대회 종료까지. 언제든 무효화할 수 있다.
- **F-045 자동 종료**: 결승선 반경 진입 후 N분 정지, 대회 제한 시간 + 1시간 경과, 코스 반경 이탈 중 하나라도 해당하면 종료한다 (P-LOC-07).
- **F-047 통신 장애 대응**: 전송에 실패하면 로컬에 버퍼링했다가 재전송한다. 화면에 "마지막 업데이트 n분 전"을 표시한다.
- 수용 기준
  - 공유 중에는 앱 상단·알림 영역에 "위치 공유 중" 표시가 항상 보인다.
  - 중지 버튼을 누르면 5초 안에 모든 시청자 화면에서 위치가 사라진다.

### Result (F-050 ~ F-053) — Phase 4
- 예측 대비 실제 기록 차이, 구간별 페이스 차이, 다음 목표 제안.

### Admin (F-080)
- 웹 관리자 도구. 대회 CRUD, 정보 오류 제보 처리, 참가 인증 승인, 신고 처리, 위치정보 열람 요청 대응.
