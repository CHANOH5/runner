## 1. 어떤 서비스인가

### 한 줄 정의
**러닝 대회를 중심으로 "대회를 찾고, 목표를 세우고, 같은 대회 러너와 함께 달리는" 대회 참가자용 소셜 앱.**

### 문제 정의
| 러너가 겪는 문제 | 현재 해결 방식 | 한계 |
|---|---|---|
| 대회 정보가 흩어져 있음 | 대회별 홈페이지, 러닝 커뮤니티, 인스타그램, 대회 일정 사이트 | 접수 오픈일을 놓침. 내 수준에 맞는 대회를 고르기 어려움 |
| 내가 이 대회를 몇 분에 뛸 수 있을지 모름 | 감으로 정하거나 온라인 계산기 사용 | 내 기록과 코스 특성이 반영되지 않음. 페이스 전략이 없음 |
| 대회에 혼자 나가면 외로움. 페이스 메이커가 없음 | 크루가 있는 사람만 함께 뜀 | 크루가 없는 러너는 같은 목표의 러너를 찾을 방법이 없음 |
| 가족·친구가 응원하러 와도 내가 어디 있는지 모름 | 가르민 LiveTrack, Strava Beacon, 대회 공식 기록 조회 | 기기·서비스마다 따로 설정해야 함. 대회 맥락(코스, 예상 도착 시간)이 없음 |
| 대회가 끝나면 다음 목표가 흐려짐 | 개인 기록 앱 | 예측 대비 결과 피드백, 다음 대회 추천이 없음 |

### 해결 방식
대회 **이전·당일·이후**를 하나의 흐름으로 묶는다. 이 흐름의 중심은 "대회"다.

## 2. 서비스 구조

```
                    ┌──────────────────────────────┐
                    │        대회 (Race)             │  ← 모든 기능의 중심 축
                    └──────────────────────────────┘
        ┌──────────────────┬───────────────────┬──────────────────┐
   [대회 전] Discover     [대회 전] Predict    [당일] Live        [대회 후] Result
   · 대회 캘린더/검색      · 기록 예측           · 위치 공유 (opt-in) · 기록 입력
   · 접수 알림             · 목표 페이스·구간전략 · 응원 링크          · 예측 vs 실제
   · 관심/참가 예정        · 페이스 그룹 매칭     · 페이스 그룹 위치   · 함께 뛴 러너 연결
                                                · 자동 종료          · 다음 대회 추천
        └──────────────────┴───────────────────┴──────────────────┘
                                   │
                       다음 대회 탐색으로 순환 (재방문 루프)
```

### 핵심 루프 (Retention Loop)
1. 대회를 찾는다 → 관심 등록 → **접수 오픈 알림**으로 재방문
2. 참가 예정 → 목표 기록 입력 → **같은 대회 참가자가 늘어나는 것을 확인**하며 재방문
3. 대회 당일 → 라이브로 응원받고 함께 달림 → **가장 강한 경험**
4. 결과 입력 → 예측 대비 피드백 → **다음 대회 추천** → 1로 돌아감

## 3. 가치 제안

| 대상 | 가치 |
|---|---|
| 러너 (핵심) | 내 수준에 맞는 대회를 찾고, 현실적인 목표를 세우고, 혼자가 아니라 함께 달린다 |
| 러닝 크루 | 크루원 대회 일정·목표를 한곳에서 관리하고 당일 서로 위치를 확인한다 |
| 응원자 (가족·친구) | 앱 설치 없이 링크 하나로 러너 위치와 예상 도착 시간을 본다 |
| 대회 주최사 (장기) | 참가자 모객 채널, 참가자 경험 향상 |

## 4. 차별점

| 서비스 | 강점 | BeRun과의 차이 |
|---|---|---|
| Strava (Beacon) | 기록·커뮤니티. Beacon으로 최대 3명에게 실시간 위치 공유, 받는 사람은 계정 없이 웹으로 확인 (모바일 무료) | 대회 탐색·예측이 없음. 같은 대회 참가자를 연결하지 않음 |
| Garmin Connect (LiveTrack, Races & Events) | 대회 캘린더·목표 기록·코스·예상 완주 기록, 웨어러블 기반 위치 공유 | **가민 기기 사용자 한정.** 같은 대회 러너 연결 없음 |
| Nike Run Club | 무료 훈련 플랜. 2024-11부터 링크로 실시간 위치 공유 (받는 사람 앱 불필요) | 대회 탐색·예측·대회 맥락이 없음 |
| 레이스캘린더, 러닝라이프 (국내 대회 일정 앱) | 전국 대회 일정·필터, 관심 대회 접수 알림. 러닝라이프는 앱 내 접수·결제, 대회 리뷰, 지역 크루 찾기까지 제공 | 내 기록 기반 예상 기록·목표 페이스가 없음. 대회 단위로 비슷한 목표의 러너를 연결하지 않음 |
| 크루와 (국내) | 배번 기반 구간 기록으로 대회 당일 예상 위치를 지도에 표시 | GPS 위치 공유가 아니라 계측 기록 기반. 대회 전 준비·러너 연결이 없음 |
| **BeRun** | **Phase 1: 대회 정보 + 내 기록 기반 예상 기록·목표 페이스를 한 화면에. 장기: 같은 대회 + 비슷한 목표 기록 + 동의한 러너끼리 연결** | 대회 전·당일·후가 하나의 흐름 |

> - 경쟁 서비스 기능은 2026-10-21 마케터 재조사(`../marketing/02-positioning.md` 1장, 출처 URL 포함) 기준이다. 스토어 설명·공식 문서 기준이며 실제 앱 사용 검증은 하지 않았다. 마케터가 분기마다 갱신한다. [확인 필요]
> - 시사점: 링크로 위치 공유하기 자체와 대회 캘린더·접수 알림은 더 이상 차별점이 아니다. Phase 1 차별점은 **"대회 + 내 예상 기록·페이스 전략"** (D-011), 장기 차별점은 **같은 대회 러너의 동의 기반 연결**과 Live의 **대회 맥락**(코스 위 구간, 예상 도착 시간)이다.

## 5. 서비스 범위 (단계별)

| 단계 | 범위 | 목적 |
|---|---|---|
| Phase 1 (MVP) | 대회 캘린더, 대회 상세, 관심/참가 예정, 접수 알림, 기록 예측 | 사용자가 모일 이유를 만든다 |
| Phase 2 | 페이스 그룹, 참가자 목록, 러너 프로필, 친구 | 대회 전부터 연결을 만든다 |
| Phase 3 | 라이브 위치 공유 베타, 응원 링크 | 당일 경험을 검증한다 |
| Phase 4 | 결과 비교, 다음 대회 추천, 구독(Runner Pro, Crew) | 수익을 검증한다 |

## 6. 수익 모델 (가설)

| 요금제 | 가격 가설 | 기능 |
|---|---|---|
| Free | 무료 | 대회 일정, 관심 대회, 기본 기록 예측, **위치 공유·응원 링크 기본 기능** |
| Runner Pro | 월 4,900원 | 개인화 예측, 목표별 훈련 리포트, 고급 기록 분석 |
| Race Pass | 대회당 1,900원 | 대회 당일 프리미엄 분석 (구간 스플릿 리포트 등) |
| Crew | 월 19,900원 | 크루 일정, 크루 페이스 그룹, 단체 참가 관리 |

> 가격은 가설이다. Phase 4 전에 마케터가 유료 의향 조사로 검증한다.
> 안전 관련 기능은 유료로 잠그지 않는다 (`CLAUDE.md` 절대 원칙).

## 7. 성공 지표 (초안)

| 단계 | 지표 |
|---|---|
| North Star | **참가 예정으로 표시된 대회 수 × 대회당 연결된 러너 수** |
| Phase 1 | 가입자 수, 관심 대회 등록률, 접수 알림 클릭률, 주간 재방문율 (정의·목표값은 `05-prd-phase1.md` 2장) |
| Phase 2 | 대회당 참가 예정 수, 페이스 그룹 참여율 |
| Phase 3 | 라이브 세션 시작률, 응원 링크 공유율, 세션 중 끊김 비율 |
| Phase 4 | 결과 입력률, 다음 대회 등록 전환율, 유료 전환율 |
