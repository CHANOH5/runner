# 04. 서비스 정책

- 담당: 기획자
- 상태: v1 초안 (검토 대기) — **법률 검토 전**
- 관련: `02-features.md`, `../tech/04-db-schema.md`

> **이 문서는 BeRun에서 가장 중요한 문서다.** 실시간 위치는 개인의 이동 경로이자 안전과 직결되는 정보다. 사용자 신뢰를 잃으면 서비스가 성립하지 않는다.
>
> `[확인 필요]` 표시는 법령 해석이나 최신 요건을 전문가(변호사, 개인정보 전문가)나 관계 기관 안내로 확인해야 하는 항목이다. 여기 적힌 법률 내용은 기획 단계의 이해일 뿐 법률 자문이 아니다.
>
> 정책은 **서버에서 강제**한다. 클라이언트 UI는 정책을 안내할 뿐이다.

## P-LOC. 위치정보 정책

### 기본 원칙
| ID | 정책 |
|---|---|
| P-LOC-01 | 위치 공유는 **기본 OFF**다. 계정 단위의 "항상 공유" 옵션은 만들지 않는다. **대회별로** 켠다. |
| P-LOC-02 | 위치 수집·공유는 사용자가 **라이브 세션 시작 버튼을 직접 눌렀을 때만** 시작한다. 예약 시작이나 자동 시작은 없다. |
| P-LOC-03 | 라이브 세션은 **참가 예정인 대회 당일, 대회 운영 시간 안에서만** 시작할 수 있다. 허용 구간은 첫 출발 2시간 전부터 제한 시간 종료 1시간 후까지다 [미정: 시간값]. |
| P-LOC-04 | 위치는 **대회 코스 주변 반경 안에서만** 다른 사람에게 노출한다. 반경 밖(예: 이동 중, 숙소, 집)에서 받은 좌표는 저장만 하고 시청자에게 전달하지 않는다 [미정: 반경 기본값 1km]. |
| P-LOC-05 | 공유 중에는 앱 화면과 OS 알림 영역에 **"위치 공유 중" 표시를 상시 노출**한다. |

### 공개 범위
| ID | 정책 |
|---|---|
| P-LOC-10 | 공개 범위는 3단계: `비공개` / `친구만` / `친구 + 참가자`. 기본값은 `친구만`이다. |
| P-LOC-11 | **정확한 좌표**를 볼 수 있는 사람: ① 상호 승인한 친구 중 사용자가 이번 대회에 선택한 사람 ② 유효한 응원 링크를 가진 사람. |
| P-LOC-12 | **같은 대회 참가자**에게는 정확 좌표를 주지 않는다. 대략 구간(1km 단위, 예: "7~8km"), 페이스 그룹, 닉네임만 보여준다. 서버에서 좌표를 코스 거리로 변환하여 **좌표 자체를 전송하지 않는다.** |
| P-LOC-13 | 참가 인증(P-VER)을 받지 않은 사용자는 다른 참가자의 대략 구간도 볼 수 없다. |
| P-LOC-14 | 차단 관계인 사용자에게는 어떤 형태로도 노출하지 않는다. 그룹 인원 수에서도 제외한다. |
| P-LOC-15 | 공개 범위는 세션 중에도 **좁히는 방향으로만** 즉시 변경할 수 있다. 넓히려면 세션을 중지하고 다시 설정해야 한다. |

## P-PRI. 개인정보 · 공개 범위

| ID | 정책 |
|---|---|
| P-PRI-01 | **최소 수집**: 실명, 전화번호, 정확한 생년월일, 주소는 받지 않는다. 생년은 연도만, 지역은 시·도 단위로 받는다. |
| P-PRI-02 | 소셜 로그인에서 받는 이메일은 계정 복구와 공지 용도로만 쓰고 다른 사용자에게 공개하지 않는다. |
| P-PRI-03 | 프로필 공개 범위: 닉네임과 프로필 사진은 기본 공개. 연령대, 성별, 지역, 기록은 각각 `전체 / 같은 대회 참가자 / 친구 / 비공개` 중에서 고른다. **기록의 기본값은 `친구`** 다. |
| P-PRI-04 | 대회 참가자 목록에는 **본인이 공개를 허락한 사람만** 표시한다. 비공개 참가자는 숫자(목표 분포 통계)에만 포함한다. 단, 5명 미만인 그룹은 통계도 표시하지 않는다 (재식별 방지). |
| P-PRI-05 | 심박수 등 건강 데이터는 Phase 4 전까지 수집하지 않는다. 도입할 때는 민감정보 해당 여부를 검토한다. [확인 필요] |
| P-PRI-06 | 배번 사진은 인증에만 쓰고, 인증이 끝나면 30일 안에 파기한다. 배번 번호는 다른 사용자에게 공개하지 않는다. |
| P-PRI-07 | 개인정보 처리방침을 앱과 웹에 게시하고, 수집 항목·목적·보존 기간·제3자 제공·처리 위탁(AWS 등)을 명시한다. |
| P-PRI-08 | 분석 도구(Amplitude, Firebase 등)에는 위치 좌표와 이메일을 보내지 않는다. |

## P-VER. 대회 참가 인증

누구나 "이 대회에 나간다"고 등록할 수 있으므로, 기능별로 필요한 인증 수준을 나눈다.

| 수준 | 방법 | 가능한 것 |
|---|---|---|
| L0 자가 등록 | 참가 예정만 표시 | 관심·알림, 기록 예측, 참가자 통계 보기 |
| L1 배번 인증 | 배번 사진 업로드 → 관리자 확인 (초기에는 수동) | 페이스 그룹 참여, 참가자 목록 보기, 라이브 지도에 표시 |
| L2 공식 인증 | 주최사 연동 또는 접수 확인 메일·문자 대조 | L1 기능 전체 + "공식 인증" 배지 |

| ID | 정책 |
|---|---|
| P-VER-01 | 라이브 지도에서 **다른 참가자의 대략 구간을 보거나 내 구간을 보여주려면 L1 이상**이 필요하다. |
| P-VER-02 | 친구·응원 링크 공유는 L0도 가능하다. 내가 선택한 사람에게 공유하는 것이기 때문이다. |
| P-VER-03 | 허위 인증이 적발되면 해당 대회 소셜 기능을 정지하고, 반복하면 계정을 정지한다. |
| P-VER-04 | 한 계정은 같은 대회에서 한 종목에만 참가 예정에 추가할 수 있다. |

## P-COM. 커뮤니티 · 안전

| ID | 정책 |
|---|---|
| P-COM-01 | 친구는 **상호 승인**으로만 맺어진다. 친구 요청은 하루 20건으로 제한한다 [미정]. |
| P-COM-02 | MVP~Phase 3에서는 **1:1 DM을 제공하지 않는다.** 페이스 그룹 공지와 출발 전 만남 제안만 제공한다. 스토킹과 괴롭힘 위험을 낮추기 위해서다. |
| P-COM-03 | 차단은 즉시 적용되고 상대에게 알리지 않는다. 차단한 사람에게는 내 프로필, 참가 대회, 그룹 내 존재, 위치가 모두 보이지 않는다. |
| P-COM-04 | 신고 사유: 스팸, 괴롭힘, 사칭, 허위 참가, 부적절한 프로필, **원치 않는 접근(스토킹)**. 스토킹 신고는 최우선으로 처리하고, 처리 중에는 피신고자의 소셜·라이브 기능을 즉시 제한한다. |
| P-COM-05 | 출발 전 만남 제안은 **공개 장소(대회장 내 지정 지점)** 로만 정한다. 자유 주소 입력은 허용하지 않는다. |
| P-COM-06 | 응원 메시지는 정해진 문구와 이모지 중에서 고르게 한다. 자유 텍스트는 Phase 4 이후에 필터와 함께 검토한다. |
| P-COM-07 | **BeRun은 응급 구조 서비스가 아니다.** 라이브 화면과 약관에 "응급 상황에는 대회 의료진이나 119에 연락하세요"를 명시한다. 위치 공유가 안전을 보장한다고 표현하지 않는다. |

| 데이터 | 보존 기간 | 비고 |

| 배번 인증 사진 | 인증 완료 후 30일 | |
| 신고 · 제재 기록 | 처리 후 1년 [미정] | 재범 판단용 |
| 동의 이력 | 계정 탈퇴 후 법정 기간 [확인 필요] | 동의 시각, 약관 버전 |
| 계정 · 프로필 · 기록 | 탈퇴 시 즉시 파기 (법정 보존 항목 제외) | Phase 1은 재가입 방지 키를 저장하지 않는다 (제재 기능이 없음). Phase 2에서 제재 도입 시 재검토 |
| 앱 내 알림 | 90일 | `notifications` |
| 대회 정보 오류 제보 | 탈퇴 시 작성자 정보만 제거(익명화)하고 내용은 보관 | 대회 정보 품질 관리용 |
| 결제 기록 | 전자상거래법 기준 [확인 필요] | Phase 4 |

| ID | 정책 |
|---|---|

| P-RET-02 | 백업에 남은 데이터도 백업 보존 주기(최대 35일 [미정]) 안에 사라지도록 백업 정책을 설정한다. |

[확인 필요: 개인정보 유효기간제(1년 미이용자 분리 보관·파기 의무)가 2023년 법 개정으로 폐지된 것으로 아는데, 현행 의무 여부와 분리 보관 필요성, 처리방침 기재 방식] |

## P-ACC. 계정 · 연령

| ID | 정책 |
|---|---|
| P-ACC-01 | **만 14세 미만은 가입할 수 없다.** 출생연도로 확인한다. `올해 − 출생연도 = 14`이면 "올해 생일이 지났나요?"를 물어 판정하고 답은 저장하지 않는다. 가입이 중단되면 서버에 아무 정보도 남기지 않는다 (`05-prd-phase1.md` 4.3). 만 14세 미만 아동의 개인정보와 위치정보는 법정대리인 동의가 필요하기 때문이다. [확인 필요: 자기 신고 방식의 충분성] |
| P-ACC-02 | 1인 1계정이 원칙이다. 소셜 계정은 연동을 추가할 수 있다. |
| P-ACC-03 | 닉네임은 2~12자 (한글·영문·숫자·`_`·`.`, 대소문자 무시 중복 불가). 욕설, 사칭(유명 선수·대회명·운영자) 닉네임은 금지한다. 변경은 7일에 1회. |
| P-ACC-04 | 탈퇴는 앱 안에서 즉시 할 수 있어야 한다 (앱스토어 정책). 탈퇴하면 진행 중인 라이브 세션과 응원 링크도 즉시 종료한다. |

## P-RACE. 대회 정보

| ID | 정책 |
|---|---|
| P-RACE-01 | BeRun은 대회 **정보 제공자**이며 접수를 대행하지 않는다. 접수, 결제, 환불은 주최 측 공식 채널로 안내한다. 앱 안의 "참가 예정"은 사용자의 의사 표시일 뿐 접수가 아니며, 화면에 "접수"로 오해될 문구(예: "참가 등록", "신청 완료")를 쓰지 않는다 (D-019). |
| P-RACE-08 | 접수 상태(접수 전 / 접수 완료 / 접수 못 함)는 **사용자 자기 기록**이다. BeRun은 실제 접수 여부를 확인하지 않으며, 접수 상태를 참가 인증(P-VER)으로 쓰지 않는다. 접수 상태는 알림 대상 판정과 통계에만 쓴다. |
| P-RACE-02 | 모든 대회 정보에 **출처와 최종 확인일**을 표시한다. "정확한 정보는 공식 홈페이지를 확인하세요"를 명시한다. |
| P-RACE-03 | 대회 정보를 자동 수집할 때는 출처 사이트의 이용약관과 robots.txt를 지키고, 이미지·글을 그대로 복제하지 않는다. 사실 정보(일시, 장소, 종목, 참가비)만 구조화해서 저장한다. **다른 대회 정보 서비스·집계 사이트의 데이터베이스를 복제하지 않는다.** 사실 정보는 공식 홈페이지 또는 주최 측에서 확인한 것만 저장한다. **자동 수집 결과는 관리자 검수 후에만 공개한다.** [확인 필요] |
| P-RACE-07 | 앱에 표시하는 출처는 공식 홈페이지 또는 주최 측만이다. 집계 사이트는 내부 발견 경로로만 기록하고, 운영자의 서면 허락을 받은 경우에만 "정보 제공: ○○"로 표시한다. |
| P-RACE-04 | 주최 측이 삭제나 수정을 요청하면 3영업일 안에 처리한다. |
| P-RACE-05 | 사용자 오류 제보는 관리자가 확인한 뒤 반영한다. 반영되면 제보자에게 알린다. |
| P-RACE-06 | 취소되거나 연기된 대회는 삭제하지 않고 상태를 표시한다. 참가 예정자와 관심 등록자에게 알린다. |
