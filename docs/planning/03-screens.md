```
[홈]          [대회]          [라이브]          [기록]          [마이]
```

## 4. 핵심 사용자 흐름

### 흐름 A — 첫 사용 → 대회 관심 등록 (Phase 1)
```
S-001 → S-002 로그인 → S-003 동의 → S-004 프로필 → S-005 최근 기록(건너뛰기 가능)
      → S-006 알림 권한 → S-010 홈 → S-020 대회 캘린더 → S-022 대회 상세 → [관심 등록]
```

### 흐름 B — 참가 예정 + 목표 설정 (Phase 1)
```
S-022 대회 상세 → [참가 예정 추가] → S-023 종목 선택
      → (기록이 있으면) 예상 기록 자동 추천 / (없으면) S-032 기록 예측으로 이동
      → 목표 기록 확정 → S-033 페이스 전략 → S-061 내 대회
      → [외부 공식 접수 링크 안내]
```

### 흐름 C — 대회 당일 라이브 (Phase 3)
```
D-1 푸시 "내일 위치 공유를 미리 설정하세요" → S-040 위치 공유 설정 (약관, 범위, 권한)
당일 홈 배너 → S-041 라이브 대기 → S-044 응원 링크를 가족에게 공유
      → [시작] → S-042 라이브 러닝 ↔ S-043 라이브 지도
      → 완주 감지 또는 [중지] → S-045 종료 요약 → S-034 완주 기록 입력
응원자: 링크 열기 → W-001 응원 웹 (위치, 예상 도착, 응원 메시지)
```

### 흐름 D — 대회 후 (Phase 4)
```
S-034 완주 기록 → S-035 예측 vs 실제 → S-052 함께 뛴 러너 → S-036 다음 대회 추천 → S-022
```
